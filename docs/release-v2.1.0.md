## Stream Deck Plugins v2.1.0

O Monitor de máquina agora instala com dois cliques.

### O que mudou

- Cada release traz o `digital.astronauta.sysmonitor.streamDeckPlugin`, o formato de instalação do
  próprio Stream Deck. Baixe, dê dois cliques e o app instala. Sem Terminal, sem Node e sem
  administrador.
- O perfil `Astronauta - Maquina.streamDeckProfile` vem na mesma release.
- O instalador é gerado e validado pelo GitHub a cada versão, com a ferramenta oficial da Elgato.
- O plugin continua igual, na versão 2.0.0.

### Instalar

1. Baixe os dois arquivos abaixo.
2. Dois cliques no `.streamDeckPlugin`.
3. Dois cliques no `.streamDeckProfile`.

Funciona no Windows 10/11 com Stream Deck + e o app do Stream Deck 6.5 ou mais novo.
